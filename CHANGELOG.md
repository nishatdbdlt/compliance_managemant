# Changelog

## 18.0.2.0.0

- Split the original single model file into clean master, standard, audit, finding/CAPA and register modules.
- Added Factory and Buyer/Audit Organization master data.
- Added multi-company fields and record rules.
- Added configurable A/B/C/D grade rules.
- Added weighted scoring using severity and checklist weight.
- Added stronger audit state validation and mandatory finding checks.
- Added default finding deadlines by severity and overdue calculations.
- Added CAPA sequence, evidence/verification controls and completion tracking.
- Added license expiry status, days-to-expiry and reminder activities.
- Added overdue finding reminder activities.
- Added safety/training/document validations.
- Added starter General Garments Compliance standard with 16 checklist controls.
- Added audit pivot/graph analysis and printable PDF report.
- Added demo factory, buyer and draft audit when Odoo demo data is enabled.
